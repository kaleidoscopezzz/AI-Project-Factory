# 虚构案例 A：政府采购离线 DEMO

请为“某市公共设备采购申请演示系统”规划开发。本案例完全虚构，不用于真实采购和合规决策。

## 已确认需求
- 用于政府采购方案现场演示；单台 Windows x64 电脑，浏览器运行，现场完全断网，无管理员权限。
- 演示人员希望展示采购申请填报、审批意见、采购执行进度、统计看板与操作记录；填报员、审批员两种演示角色。
- 数据全部虚构；申请编号唯一；提交后锁定申请正文，退回后可以修改重提；取消确认不改变状态或操作记录；统计与申请记录一致。
- 单机演示进度刷新仍保留；能够选择“标准/退回”演示场景并重置演示数据。重置必须确认。
- 所有图片、字体及图表资源现场不依赖互联网。目标浏览器视口为 1920×1080、1366×768。
- 不接真实政务账号、预算平台、支付、电子签章，不声称达到真实生产授权或法定采购审批要求。
- 开发机器可联网准备依赖；现场不要求安装 Node/Git/包管理器。正式现场包装单列后续阶段，Goal 0 先验证可运行工程基础。
- Goal 0 只建主框架、身份演示、导航、数据与状态基座和一个可修改/刷新/重置的基础样板；不开发完整采购业务。

## 需要澄清但不阻塞基座的部分
审批层级、金额阈值、退回后的版本留痕规则尚未给出，不得擅自定成正式业务规则；请列出阻塞的业务任务。
