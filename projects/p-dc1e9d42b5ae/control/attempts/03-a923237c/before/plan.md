## 定位与边界
目标用户为需要在本机断网展示图书管理界面的演示人员。业务结果为能查看图书及借阅状态、执行简单搜索，并在后续阶段增量加入借还功能。当前为 DEMO，不接入真实读者、身份、生产数据或外部系统。

用户明确：离线、图书列表、借阅状态、简单搜索、专业界面、方便扩展。用户提供的环境事实：Windows PowerShell、Python 3.14.6、Node 26.3.0、禁止外部网络、本机 Playwright 路径。上述版本未由 Planner 重测。用户提供的工厂基线为 main / 11aa80e / goal-0-approved；子工程无自身 Git 仓库，不能把工厂提交当成本工程 HEAD。

可撤销假设：单人本机浏览器演示；全部样例为虚构；Goal 0 使用三条固定图书样例验证列表、状态、搜索，另用显式“工程验证”备注编辑串通持久化，不提前实现完整借还流程。样例规模和视觉数值是工程设计，不是用户业务指标。

本次范围：运行配置、统一布局、图书样例列表、状态展示、搜索、工程备注持久化样板、异常与取消、离线和真实浏览器验证、证据与状态文档。范围外：借出/归还事务、读者管理、真实认证、库存册副本建模、逾期费用、预约、批量导入、生产数据库、云服务、安装发行包和发布。

成功指标：Goal 0 的 AC-001 至 AC-012 全部有实际可观察结果与证据，构建和测试成功，浏览器真实交互及刷新/进程重启链路完成，随后只进入待外部 Reviewer 验收状态。
