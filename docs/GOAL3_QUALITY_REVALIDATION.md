# Goal 3 质量复验与来源复核

APF Goal 3 已按受控双阶段真实交付范围批准，Tag 为 `goal-3-approved`。本文描述已有案例的有限质量接续，不是新调度器、任意项目恢复接口或需要重新执行的验收任务。当前功能说明见 [阶段机制](GOAL3_INCREMENT.md)。

## 已实现范围

既有独立复验执行器增加 Goal 3 特定来源支持，继续复用 QualityGate。它验证合法 Planner/Coder、TaskPacket、completion、候选和历史材料，以新上下文保留原始失败账本及所有证据。不能直接改旧 blocked 状态，不能重放已耗尽的授权。

待办 Goal 0 的真实 Tester 结果包含一次后来成功恢复的辅助哈希枚举事件。有限零模型派生复核依据原失败命令、修正后真实命令与哈希结果，保留旧原件；随后真实独立只读 Reviewer 批准，形成正式阶段记录。

Goal 1 的宿主授权后缀输入哈希问题及额外非正式 AC-012 通过独立、来源绑定的零模型视图处理。正式四项 AC 和原始 Reviewer 补充判断全部保留，源码引用仅供只读审查；它不代替 Tester 命令证据，也不开放忽略未知问题的通用例外。

## 不变的约束

来源、副本、任务包及候选 SHA 必须一致；关键证据缺失、篡改、路径越界或真实业务失败仍阻止批准。普通相对文件引用按可信文档语义解析，不进行任意同名文件搜索。历史材料不能直接继承为本轮 passed。

新授权与调用额度由该轮范围决定，不从历史账本复制。Reviewer 必须在合法 Tester 条件满足后独立执行。Full Access 无 OS 隔离，Token 无硬上限，原始失败保留。正式结果通过既有阶段机制保存；内部软件批准与 APF 外部封版分开。
